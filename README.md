# 水下考古潜水记录

直接打开`index.html`使用。点击平面图添加标记，支持筛选、编辑、删除、时间线和导出JSON。

## 船载暂存与吊运配载台

每件出水物登记**湿重、包装等级（A加固/B标准/C简易）、起吊时刻**。转运架各有承重上限、材质分区（陶瓷/木作/金属/通用）、架位数与吊带等级（S1/S2/S3）。

配载规则（不满足则留在待配载区）：

- 湿重超出转运架承重余量 → 超重
- 易碎品（陶瓷类或C级简易包装）与金属件不得同架
- 湿重决定所需吊带等级（<30kg需S1，<100kg需S2，≥100kg需S3），架吊带等级不足不可上架
- 材质分区须匹配（通用架除外），架位有限

调整重量、类型或包装后，原架位立即失效并按新值重排；未变动的已占架位不会被其他件抢走。页面可按潜次查看待配载、已配载与冲突清单，点击条目可直接编辑。

## 文件结构

- `index.html` — 页面结构与样式
- `js/allocation.js` — 配载判定（纯规则计算）
- `js/storage.js` — 暂存档案（标记与转运架的读写、迁移）
- `js/ui.js` — 页面操作（地图、表单、配载台渲染、导出）
